# Official MSX public renderer/player milestone — 2026-10-30

**Implemented / browser-tested / device-unverified:** a reproducible public
renderer/player fixture and actual official-MSX observations for part of #9.
This is not the complete application E2E suite. Normal hosted pairing, private
source delivery and dynamic authorization/failure recovery remain open in #9.

## Provenance and boundaries

`tools/public_msx_fixture.py` creates the real production application with the
isolated synthetic transport. It obtains library, browse, playable detail,
HD-denied detail and PlaybackInfo responses after normal synthetic GET/CSRF POST
pairing. No backend state is injected or authenticated route bypassed.

Before writing anything public, it replaces every private navigation action with
[documented](https://msx.benzac.de/wiki/index.php?title=Internal_Actions) inline
`content:data` navigation, private diagnostic/disconnect actions
with scope notices, and the resolver action with a **substituted public video**.
The poster also uses a public asset URL. It refuses unexpected action types and
guards against private-origin/capability/code/credential/media-URL leakage. This
guard is not a sanitizer for arbitrary URLs: supply only a known public synthetic
asset directory. Exported pages prominently identify the public-fixture scope.
Their successful playback is not proof of production source dispatch.

The committed clip is independently encoded testsrc2 video plus a quiet 440 Hz
tone, generated by the existing `tools/make_test_clip.py` with FFmpeg 7.1 supplied
by an ignored local `imageio-ffmpeg==0.6.0` PyPI wheel. It is not an application
dependency. No operator media or Ultra encoding was used. A local complete decode
to FFmpeg's null output completed all 720 frames without error. Properties:
30 seconds, H.264 Main, yuv420p, 1280x720, 24 fps, AAC-LC stereo, 48 kHz,
4,131,521 bytes. SHA256:
`44f03da6c498584f27f5f04471935dc2ec5931769e28fbaf7c0a91fcff8fc406`.
The independent RGB PNG is a 240x360 green-to-yellow gradient; automated checks
validate its PNG structure, checksums and pixel data.

Only our public fixtures/assets are served by the shared source-preview service.
No proprietary runtime was copied, hosted, modified or inspected internally.
No certificate/trust import, TLS bypass, production deployment, live credentials,
operator-server request or browser permission change occurred. Never use this
shared origin for real passwords, tokens or device-renewal secrets.

`4660d7ffdaf4314f0bb645a85ee5095e557d6392`; it pins assets at

```sh
uv sync --locked --extra dev
uv run pytest tests/test_public_msx_fixture.py
uv run python -m tools.msx_storage_probe https://raw.githack.com/alexanderhetzel/jellyfin-msx/4660d7ffdaf4314f0bb645a85ee5095e557d6392/tests/fixtures/msx-public/index.json
```

Open the printed official URL in the connected Chrome extension. This is a
**launch command**, not an automated complete E2E assertion command. Click
Synthetic movies, Synthetic clip and Try original, inspect screenshots and run
the player checks below. To regenerate the public pages into a disposable local
directory without contacting any server:

```sh
uv run python -m tools.public_msx_fixture https://raw.githack.com/alexanderhetzel/jellyfin-msx/998bc0829b2df06db568443803a6fb4533e23f40/tests/fixtures/msx-public --output .lab/public-msx
```

Tests compare committed JSON with this current production-derived export,
validate all nested action targets, deny HD playback and prohibit real upstream
HTTP transport. CI stays synthetic/offline; it does not operate a browser. The
hosted runtime and shared HTTPS preview are external, unpinned services even
though our source/assets are commit-pinned. Record availability, version and
loading failures separately. Do not bypass source-preview or browser warnings.

## Actual environment and results

Official MSX **0.1.167 web**, connected Chrome extension, Windows, existing
`Mein Chrome` profile used by #11 (Chrome 156 was recorded there). Browser version
was not independently reread here: the read-only DOM evaluation surface did not
expose `navigator`. Screenshots use the normal window (2560x1215 content captures),
without a viewport override. Top-level origin `https://msx.benzac.de`, public
fixture origin `https://raw.githack.com`; standalone image navigation redirected
to `raw.githubusercontent.com`. Profile/partition settings were not changed.
Launch parameters: `input=2`, `init=1`, `suspend=0`, `animate=0`.

All actions below used actual visible MSX DOM-backed clicks. Safe read-only
video properties were inspected; no `src`, hidden application state or runtime
internals were read, and no media time/playback setters were used.

inspected. Neither tooling timeout is a physical remote-control failure. One
transient Stop screenshot was white/stale; the settled Stop/detail and
post-failure library captures provide the usable-UI evidence instead.
